# Core

`core/` chứa phần dùng chung toàn app.

| Thư mục | Nội dung |
| --- | --- |
| `constants/` | API URL, storage keys, app constants |
| `session/` | Lưu/đọc JWT và thông tin phiên |
| `theme/` | Color, typography, Material theme |
| `utils/` | Format tiền/ngày/text, validators |
| `widgets/` | Component UI tái sử dụng |

Ưu tiên đặt widget dùng chung tại đây khi nó xuất hiện ở nhiều màn hình hoặc nhiều role.
