# Presentation

`presentation/` chứa màn hình theo luồng người dùng.

| Thư mục | Nội dung |
| --- | --- |
| `auth/` | Login, register, reset password |
| `admin/` | Dashboard admin, host management, room audit, revenue, profile |
| `host/` | Dashboard và các màn vận hành của chủ trọ |
| `tenant/` | Dashboard, hợp đồng, hóa đơn, sự cố, dịch vụ, chatbot, profile |

Màn hình nên tập trung vào UI và interaction. State/data đi qua provider và service.
